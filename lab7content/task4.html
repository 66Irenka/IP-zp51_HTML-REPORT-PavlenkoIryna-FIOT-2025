Завдання №4. Галерея зображень

У цьому завданні реалізовано галерею зображень. Дані для галереї зберігаються в масиві об’єктів, а HTML-розмітка створюється динамічно за допомогою JavaScript.

HTML-код галереї


<ul class="gallery"></ul>

Приклад масиву зображень


const images = [
  {
    preview: "small-image.jpg",
    original: "large-image.jpg",
    description: "Опис зображення",
  },
];

Пояснення роботи

Кожне зображення описується об’єктом із трьома властивостями: preview, original та description. На основі цього масиву JavaScript створює список елементів галереї.

Для відкриття великого зображення використовується делегування подій. Обробник кліку встановлюється не на кожну картинку окремо, а на спільний контейнер ul.gallery. Якщо користувач натискає саме на зображення, відкривається модальне вікно.

Основна логіка JavaScript


const gallery = document.querySelector(".gallery");

const markup = images
  .map(({ preview, original, description }) => {
    return `
      <li class="gallery-item">
        <a class="gallery-link" href="${original}">
          <img
            class="gallery-image"
            src="${preview}"
            data-source="${original}"
            alt="${description}"
          />
        </a>
      </li>
    `;
  })
  .join("");

gallery.innerHTML = markup;

gallery.addEventListener("click", event => {
  event.preventDefault();

  if (event.target.nodeName !== "IMG") {
    return;
  }

  const largeImageURL = event.target.dataset.source;

  const instance = basicLightbox.create(`
    <img src="${largeImageURL}" alt="${event.target.alt}" />
  `);

  instance.show();
});

Що використано у завданні

  • масив об’єктів;
  • метод map();
  • метод join();
  • динамічне створення HTML-розмітки;
  • делегування подій;
  • атрибут data-source;
  • бібліотека basicLightbox.

Результат виконання

На сторінці відображається галерея зображень. При кліку на картинку відкривається модальне вікно з її збільшеною версією.
