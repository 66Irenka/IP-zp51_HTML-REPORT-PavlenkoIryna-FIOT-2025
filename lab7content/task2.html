Завдання №2. Форма зворотного зв’язку

У цьому завданні реалізовано форму зворотного зв’язку. Дані, які користувач вводить у поля Email та Message, автоматично зберігаються у локальне сховище браузера — localStorage.

HTML-код форми


<form class="feedback-form" autocomplete="off">
  <label>
    Email
    <input type="email" name="email" autofocus />
  </label>

  <label>
    Message
    <textarea name="message" rows="8"></textarea>
  </label>

  <button type="submit">Submit</button>
</form>

Фрагмент JavaScript коду


const STORAGE_KEY = 'feedback-form-state';

const form = document.querySelector('.feedback-form');

let formData = {
  email: '',
  message: '',
};

form.addEventListener('input', handleInput);
form.addEventListener('submit', handleSubmit);

function handleInput(event) {
  const fieldName = event.target.name;
  const fieldValue = event.target.value.trim();

  formData[fieldName] = fieldValue;

  localStorage.setItem(
    STORAGE_KEY,
    JSON.stringify(formData)
  );
}

function handleSubmit(event) {
  event.preventDefault();

  if (!formData.email || !formData.message) {
    alert('Fill please all fields');
    return;
  }

  console.log(formData);

  localStorage.removeItem(STORAGE_KEY);
  form.reset();
}

Пояснення роботи

Для збереження даних використовується об'єкт formData, який містить поля email та message. На форму встановлено обробники подій input і submit.

Під час введення тексту викликається функція handleInput(), яка отримує назву поля через event.target.name, записує введене значення до об'єкта formData та зберігає його у локальне сховище за допомогою localStorage.setItem().

При натисканні кнопки Submit викликається функція handleSubmit(). Спочатку виконується перевірка заповнення обох полів. Якщо хоча б одне поле порожнє, користувач отримує повідомлення про помилку. Якщо всі поля заповнені, дані виводяться у консоль, локальне сховище очищується, а форма скидається до початкового стану.

Що використано у завданні

  • HTML-форма;
  • подія input;
  • подія submit;
  • об'єкт localStorage;
  • методи setItem() та removeItem();
  • методи JSON.stringify() та JSON.parse();
  • об'єкт event;
  • метод form.reset().

Результат виконання

На сторінці відображається форма з двома полями та кнопкою Submit. Введені дані автоматично зберігаються у localStorage і відновлюються після перезавантаження сторінки. Після успішного надсилання форми дані виводяться у консоль, а форма та сховище очищуються.
