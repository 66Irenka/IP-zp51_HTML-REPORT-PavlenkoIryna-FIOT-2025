Завдання №2. Форма зворотного зв’язку

У цьому завданні реалізовано форму зворотного зв’язку. Дані, які користувач вводить у поля Email та Message, автоматично зберігаються у локальне сховище браузера — localStorage.

HTML-код форми


<form class="feedback-form" autocomplete="off">
  <label>
    Email
    <input type="email" name="email" autofocus />
  </label>

  <label>
    Message
    <textarea name="message" rows="8"></textarea>
  </label>

  <button type="submit">Submit</button>
</form>

Пояснення роботи

Для збереження даних використовується об’єкт formData, який містить два поля: email та message. Коли користувач вводить текст у будь-яке поле форми, спрацьовує подія input.

Після кожної зміни актуальні дані записуються у localStorage під ключем feedback-form-state. Завдяки цьому після оновлення сторінки введені значення не зникають.

Основна логіка JavaScript


const form = document.querySelector(".feedback-form");

const STORAGE_KEY = "feedback-form-state";

let formData = {
  email: "",
  message: "",
};

form.addEventListener("input", event => {
  formData[event.target.name] = event.target.value.trim();
  localStorage.setItem(STORAGE_KEY, JSON.stringify(formData));
});

form.addEventListener("submit", event => {
  event.preventDefault();

  if (!formData.email || !formData.message) {
    alert("Fill please all fields");
    return;
  }

  console.log(formData);

  localStorage.removeItem(STORAGE_KEY);
  formData = { email: "", message: "" };
  form.reset();
});

Що використано у завданні

  • форма HTML;
  • подія input;
  • подія submit;
  • об’єкт localStorage;
  • методи JSON.stringify() та JSON.parse();
  • метод form.reset().

Результат виконання

На сторінці відображається форма з двома полями та кнопкою Submit. При введенні даних вони зберігаються у локальне сховище. При відправленні форми виконується перевірка заповнення полів, після чого дані виводяться в консоль, а форма очищається.
