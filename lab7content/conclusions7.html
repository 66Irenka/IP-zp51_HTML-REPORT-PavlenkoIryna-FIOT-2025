Висновки

У ході виконання лабораторної роботи було закріплено навички роботи з сучасними засобами розробки веб-застосунків мовою JavaScript. Було опрацьовано принципи модульності коду, роботу з локальним сховищем браузера (Web Storage API), асинхронне програмування, проміси та виконання HTTP-запитів до зовнішніх API.

Під час виконання роботи було реалізовано таймер зворотного відліку з використанням бібліотеки flatpickr, форму зворотного зв’язку зі збереженням даних у localStorage, генератор промісів із використанням Promise та обробників then() і catch(), галерею зображень із модальним вікном на основі basicLightbox, а також застосунок для пошуку зображень через REST API Pixabay.

У процесі роботи було набуто практичних навичок використання Fetch API, динамічного створення HTML-розмітки, делегування подій, роботи з JSON-даними, обробки асинхронних операцій та інтеграції сторонніх JavaScript-бібліотек. Отримані знання можуть бути використані під час розробки сучасних клієнтських веб-застосунків різного рівня складності.
