Завдання №5. Пошук зображень через API

У цьому завданні реалізовано застосунок для пошуку зображень за ключовим словом. Користувач вводить пошуковий запит у форму, після чого виконується HTTP-запит до сервісу Pixabay API та отримані зображення відображаються у вигляді галереї.

HTML-код форми пошуку


<form class="search-form">
  <input
    type="text"
    name="searchQuery"
    placeholder="Search images..."
    required
  />

  <button type="submit">Search</button>
</form>

<ul class="gallery"></ul>

Фрагмент JavaScript коду


import axios from 'axios';
import iziToast from 'izitoast';

const API_KEY = 'YOUR_API_KEY';

const form = document.querySelector('.search-form');
const gallery = document.querySelector('.gallery');

form.addEventListener('submit', handleSubmit);

function handleSubmit(event) {
  event.preventDefault();

  const query =
    event.target.elements.searchQuery.value.trim();

  if (!query) {
    iziToast.warning({
      message: 'Please enter a search query',
    });

    return;
  }

  gallery.innerHTML = '';

  fetchImages(query);
}

function fetchImages(query) {
  axios
    .get('https://pixabay.com/api/', {
      params: {
        key: API_KEY,
        q: query,
        image_type: 'photo',
        orientation: 'horizontal',
        safesearch: true,
      },
    })
    .then(response => {
      renderGallery(response.data.hits);
    })
    .catch(error => {
      console.log(error);
    });
}

Створення карток галереї


function renderGallery(images) {
  const markup = images
    .map(
      image => `
      <li class="gallery-item">
        <a href="${image.largeImageURL}">
          <img
            src="${image.webformatURL}"
            alt="${image.tags}"
          />
        </a>

        <div class="info">
          <p><b>Likes</b><br>${image.likes}</p>
          <p><b>Views</b><br>${image.views}</p>
          <p><b>Comments</b><br>${image.comments}</p>
          <p><b>Downloads</b><br>${image.downloads}</p>
        </div>
      </li>
    `
    )
    .join('');

  gallery.innerHTML = markup;
}

Пояснення роботи

На форму встановлено обробник події submit. Після введення ключового слова викликається функція handleSubmit(), яка отримує пошуковий запит та перевіряє його коректність.

Для виконання HTTP-запиту використовується бібліотека axios. Запит надсилається до сервісу Pixabay API із параметрами пошуку: ключем доступу, пошуковим словом, типом зображення, орієнтацією та параметром безпечного пошуку.

Після отримання відповіді функція renderGallery() створює HTML-розмітку карток зображень за допомогою методу map(). Для кожного зображення відображаються кількість вподобань, переглядів, коментарів та завантажень.

Якщо користувач не ввів пошуковий запит або за результатами пошуку не знайдено жодного зображення, відображається повідомлення за допомогою бібліотеки iziToast.

Що використано у завданні

  • HTML-форма пошуку;
  • подія submit;
  • HTTP-запити;
  • REST API Pixabay;
  • бібліотека axios;
  • методи then() та catch();
  • динамічне створення HTML-розмітки;
  • метод map();
  • бібліотека iziToast;
  • робота з JSON-даними.

Результат виконання

На сторінці відображається форма пошуку зображень. Після введення ключового слова та натискання кнопки Search виконується запит до Pixabay API, а знайдені зображення автоматично відображаються у галереї. Для кожного зображення додатково показується статистика переглядів, вподобань, коментарів та завантажень.
