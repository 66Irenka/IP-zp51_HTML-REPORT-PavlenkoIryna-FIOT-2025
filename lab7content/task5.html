Завдання №5. Пошук зображень через API

У цьому завданні реалізовано застосунок для пошуку зображень за ключовим словом. Користувач вводить запит у форму пошуку, після чого виконується HTTP-запит до публічного API Pixabay.

HTML-код форми пошуку


<form class="search-form">
  <input
    type="text"
    name="searchQuery"
    placeholder="Search images..."
    required
  />

  <button type="submit">Search</button>
</form>

<ul class="gallery"></ul>

Пояснення роботи

Після відправлення форми значення з поля пошуку зчитується у JavaScript. Якщо поле порожнє, користувач отримує повідомлення про помилку. Якщо запит введено правильно, виконується HTTP-запит до API.

У запиті використовуються параметри: ключ доступу, пошукове слово, тип зображення, орієнтація та безпечний пошук. Після отримання відповіді зображення динамічно додаються на сторінку у вигляді галереї.

Основна логіка JavaScript


const form = document.querySelector(".search-form");
const gallery = document.querySelector(".gallery");

form.addEventListener("submit", event => {
  event.preventDefault();

  const query = event.target.elements.searchQuery.value.trim();

  if (!query) {
    return;
  }

  gallery.innerHTML = "";

  fetchImages(query)
    .then(images => {
      if (images.length === 0) {
        alert("Sorry, there are no images matching your search query. Please try again!");
        return;
      }

      gallery.innerHTML = createGalleryMarkup(images);
    })
    .catch(error => {
      console.error(error);
    });
});

Створення розмітки карток


function createGalleryMarkup(images) {
  return images
    .map(image => {
      return `
        <li class="gallery-item">
          <a href="${image.largeImageURL}">
            <img src="${image.webformatURL}" alt="${image.tags}" />
          </a>

          <div class="info">
            <p>Likes: ${image.likes}</p>
            <p>Views: ${image.views}</p>
            <p>Comments: ${image.comments}</p>
            <p>Downloads: ${image.downloads}</p>
          </div>
        </li>
      `;
    })
    .join("");
}

Що використано у завданні

  • форма пошуку;
  • подія submit;
  • метод fetch();
  • HTTP-запит до Pixabay API;
  • методи then() і catch();
  • динамічне створення HTML-розмітки;
  • бібліотека SimpleLightbox для перегляду великих зображень;
  • бібліотека iziToast для повідомлень;
  • індикатор завантаження.

Результат виконання

На сторінці відображається форма пошуку. Після введення ключового слова завантажуються зображення з API та виводяться у галерею. При кліку на зображення відкривається його збільшена версія.
