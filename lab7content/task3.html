Завдання №3. Генератор промісів

У цьому завданні реалізовано генератор промісів. Користувач вводить затримку в мілісекундах, обирає стан промісу — fulfilled або rejected — і натискає кнопку Create notification.

HTML-код форми


<form class="form">
  <label>
    Delay (ms)
    <input type="number" name="delay" required />
  </label>

  <fieldset>
    <legend>State</legend>

    <label>
      <input type="radio" name="state" value="fulfilled" required />
      Fulfilled
    </label>

    <label>
      <input type="radio" name="state" value="rejected" required />
      Rejected
    </label>
  </fieldset>

  <button type="submit">Create notification</button>
</form>

Пояснення роботи

Після відправлення форми створюється новий проміс. Якщо користувач обрав fulfilled, проміс успішно виконується через задану кількість мілісекунд. Якщо обрано rejected, проміс відхиляється.

Основна логіка JavaScript


const form = document.querySelector(".form");

form.addEventListener("submit", event => {
  event.preventDefault();

  const delay = Number(event.target.elements.delay.value);
  const state = event.target.elements.state.value;

  const promise = new Promise((resolve, reject) => {
    setTimeout(() => {
      if (state === "fulfilled") {
        resolve(delay);
      } else {
        reject(delay);
      }
    }, delay);
  });

  promise
    .then(delay => {
      console.log(`✅ Fulfilled promise in ${delay}ms`);
    })
    .catch(delay => {
      console.log(`❌ Rejected promise in ${delay}ms`);
    });

  form.reset();
});

Що використано у завданні

  • форма HTML;
  • подія submit;
  • об’єкт Promise;
  • методи resolve() та reject();
  • методи then() і catch();
  • функція setTimeout();
  • бібліотека iziToast для повідомлень.

Результат виконання

Після натискання кнопки створюється проміс, який через задану затримку виконується або відхиляється. Користувач бачить повідомлення про результат виконання промісу.
