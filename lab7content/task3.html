Завдання №3. Генератор промісів

У цьому завданні реалізовано генератор промісів. Користувач вводить затримку в мілісекундах, обирає стан промісу — fulfilled або rejected — і натискає кнопку Create notification.

HTML-код форми


<form class="form">
  <label>
    Delay (ms)
    <input type="number" name="delay" required />
  </label>

  <fieldset>
    <legend>State</legend>

    <label>
      <input type="radio" name="state" value="fulfilled" required />
      Fulfilled
    </label>

    <label>
      <input type="radio" name="state" value="rejected" required />
      Rejected
    </label>
  </fieldset>

  <button type="submit">Create notification</button>
</form>

Фрагмент JavaScript коду


const form = document.querySelector('.form');

form.addEventListener('submit', handleSubmit);

function handleSubmit(event) {
  event.preventDefault();

  const delay = Number(form.elements.delay.value);
  const state = form.elements.state.value;

  createPromise(delay, state)
    .then(delay => {
      iziToast.success({
        message: `✅ Fulfilled promise in ${delay}ms`,
        position: 'topRight',
      });
    })
    .catch(delay => {
      iziToast.error({
        message: `❌ Rejected promise in ${delay}ms`,
        position: 'topRight',
      });
    });

  form.reset();
}

function createPromise(delay, state) {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      if (state === 'fulfilled') {
        resolve(delay);
      } else {
        reject(delay);
      }
    }, delay);
  });
}

Пояснення роботи

На форму встановлено обробник події submit. Після натискання кнопки Create notification отримуються значення затримки та стану промісу, обраного користувачем.

Функція createPromise() створює новий об'єкт Promise. Усередині промісу використовується функція setTimeout(), яка запускається через задану кількість мілісекунд.

Якщо користувач обрав значення fulfilled, викликається метод resolve() і проміс переходить у стан успішного виконання. Якщо обрано rejected, викликається метод reject() і проміс відхиляється.

Результат обробляється за допомогою методів then() та catch(). Для відображення повідомлень використовується бібліотека iziToast, яка показує повідомлення про успішне або неуспішне виконання промісу.

Що використано у завданні

  • HTML-форма;
  • подія submit;
  • об'єкт Promise;
  • методи resolve() та reject();
  • методи then() та catch();
  • функція setTimeout();
  • бібліотека iziToast;
  • стрілкові функції (Arrow Functions).

Результат виконання

Після натискання кнопки Create notification створюється проміс, який через задану кількість мілісекунд або успішно виконується, або відхиляється. Користувач отримує відповідне повідомлення із зазначенням часу затримки та результату виконання промісу.
