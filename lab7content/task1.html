Завдання №1. Таймер зворотного відліку

У цьому завданні реалізовано таймер зворотного відліку до обраної користувачем дати. Користувач обирає дату і час, після чого натискає кнопку Start, і на сторінці відображається кількість днів, годин, хвилин і секунд, що залишилися.

<button type="button" data-start>Start</button>

Фрагмент JavaScript коду


flatpickr(datePicker, {
  enableTime: true,
  time_24hr: true,
  defaultDate: new Date(),

  onClose(selectedDates) {
    const selectedDate = selectedDates[0];

    if (selectedDate <= new Date()) {
      iziToast.error({
        message: 'Please choose a date in the future',
      });

      startBtn.disabled = true;
      return;
    }

    userSelectedDate = selectedDate;
    startBtn.disabled = false;
  },
});

function startTimer() {
  startBtn.disabled = true;
  datePicker.disabled = true;

  timerId = setInterval(() => {
    const timeLeft = userSelectedDate - new Date();

    if (timeLeft <= 0) {
      clearInterval(timerId);
      updateTimerFace(0);
      return;
    }

    updateTimerFace(timeLeft);
  }, 1000);
}

Пояснення роботи

Для вибору дати використовується поле введення з id datetime-picker. Бібліотека flatpickr забезпечує зручний вибір дати та часу. Після закриття календаря виконується перевірка, чи знаходиться вибрана дата в майбутньому.

Якщо користувач обрав дату з минулого, за допомогою бібліотеки iziToast відображається повідомлення про помилку і кнопка Start залишається неактивною. Якщо дата коректна, кнопка стає доступною для запуску таймера.

Після натискання кнопки Start запускається функція startTimer(). За допомогою setInterval() щосекунди обчислюється різниця між поточною та кінцевою датою, після чого оновлюються значення днів, годин, хвилин і секунд на сторінці.

Що використано у завданні

  • подія click;
  • робота з датами через об’єкт Date;
  • функція setInterval();
  • форматування чисел через padStart();
  • бібліотека flatpickr для вибору дати;
  • бібліотека iziToast для повідомлень.

Результат виконання

На сторінці відображається поле вибору дати, кнопка запуску таймера та блок із відліком часу у форматі: дні, години, хвилини та секунди. Після запуску таймера дані автоматично оновлюються кожну секунду до досягнення кінцевої дати.
