Тема, мета лабораторної роботи №8

Тема

Модульність коду. Node.js. JSON. Web Storage API. Асинхронність. Проміси. HTTP-запити. REST API. AJAX. Крос-доменні запити. Пагінація. CRUD.

Мета

Мета лабораторної роботи — придбати практичні навички роботи з Web Storage API, асинхронним JavaScript, промісами, HTTP-запитами, REST API, Fetch API, модальними вікнами, галереєю зображень, таймером зворотного відліку та пошуком зображень через публічний API.

Структура виконаної роботи

У межах лабораторної роботи було реалізовано такі завдання:

  • таймер зворотного відліку;
  • форма зворотного зв’язку з використанням localStorage;
  • генератор промісів;
  • галерея зображень із модальним вікном;
  • пошук зображень через API.

Місце розташування проєкту

Практична частина лабораторної роботи розміщена в окремому проєкті. У звіті наведено опис виконання завдань, фрагменти коду та результати роботи.
