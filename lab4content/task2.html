Умова завдання

Змінна number може набувати одного з чотирьох значень: '1', '2', '3' або '4'. Необхідно визначити пору року за введеним значенням, використовуючи оператор switch. Результат вивести в консоль браузера.

Програмний код


function task2() {
    
  const number = prompt("Введіть номер пори року (1-4):");
  let season;

  switch (number) {
    case "1":
      season = "Весна";
      break;

    case "2":
      season = "Літо";
      break;

    case "3":
      season = "Осінь";
      break;

    case "4":
      season = "Зима";
      break;

    default:
      season = "Некоректне значення";
  }

  console.log(season);
}
