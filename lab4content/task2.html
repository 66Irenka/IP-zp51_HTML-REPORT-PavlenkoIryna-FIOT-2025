Завдання №2

Умова завдання

Змінна number може набувати чотири значення: '1', '2', '3' або '4'. Потрібно запитати це значення у користувача через prompt(). Якщо значення дорівнює '1', у змінну result записати зима, якщо '2' — весна, якщо '3' — літо, якщо '4' — осінь. Завдання розв’язати через switch-case. Результат вивести в консоль.

Програмний код


function task2() {
  const number = prompt("Введіть число від 1 до 4:");

  let result;

  switch (number) {
    case "1":
      result = "зима";
      break;

    case "2":
      result = "весна";
      break;

    case "3":
      result = "літо";
      break;

    case "4":
      result = "осінь";
      break;

    default:
      result = "некоректне значення";
  }

  console.log(`Результат: ${result}`);
}

Результат виконання

При введенні значення 3 у консоль буде виведено: Результат: літо.

Висновок

У завданні було використано оператор switch-case, який дозволяє вибрати один із декількох варіантів залежно від введеного користувачем значення.
