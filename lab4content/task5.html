Завдання №5

Умова завдання

Функція checkForSpam(message) приймає рядок і перевіряє його на вміст заборонених слів spam і sale. Слова можуть бути написані у довільному регістрі, наприклад SPAM або sAlE.

Якщо знайдено заборонене слово, функція повертає true. Якщо заборонених слів немає — повертає false.

Програмний код


function task5() {
    
  function checkForSpam(message) {
    const normalizedMessage = message.toLowerCase();

    return (
      normalizedMessage.includes("spam") ||
      normalizedMessage.includes("sale")
    );
  }

  console.log(checkForSpam("Buy huge SALE now!"));
  console.log(checkForSpam("This is just a normal message"));
  console.log(checkForSpam("Get rid of SPAM"));
}

Висновок

У завданні було використано метод toLowerCase() для приведення рядка до нижнього регістру та метод includes() для перевірки наявності заборонених слів у тексті.
