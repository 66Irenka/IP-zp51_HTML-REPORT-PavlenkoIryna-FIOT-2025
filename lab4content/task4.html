Завдання №4

Умова завдання

Оголосити функцію makeTransaction, яка очікує два параметри: quantity — кількість замовлених дроїдів та pricePerDroid — вартість одного дроїда. Функція має повертати рядок з повідомленням про покупку.

Програмний код


function task4() {
    
  function makeTransaction(quantity, pricePerDroid) {
    const totalPrice = quantity * pricePerDroid;

    return `You ordered ${quantity} droids worth ${totalPrice} credits!`;
  }

  console.log(makeTransaction(5, 3000));
  console.log(makeTransaction(3, 1500));
  console.log(makeTransaction(10, 500));
}

Результат виконання

У консолі буде виведено: 


You ordered 5 droids worth 15000 credits!
You ordered 3 droids worth 4500 credits!
You ordered 10 droids worth 5000 credits!
