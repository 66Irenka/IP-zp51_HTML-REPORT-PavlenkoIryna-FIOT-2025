Завдання №6

Умова завдання

Написати функцію filterArray(numbers, value), яка приймає масив чисел та значення. Функція має повернути новий масив, що містить лише ті числа, які більші за задане значення value.

Програмний код


function task6() {
    
  function filterArray(numbers, value) {
    const filteredNumbers = [];

    for (let i = 0; i < numbers.length; i += 1) {
      const number = numbers[i];

      if (number > value) {
        filteredNumbers.push(number);
      }
    }

    return filteredNumbers;
  }

  console.log(filterArray([1, 2, 3, 4, 5], 3));
}

Результат виконання


[4, 5]

Висновок

У завданні було використано цикл for, умовний оператор if та метод push() для формування нового масиву.
