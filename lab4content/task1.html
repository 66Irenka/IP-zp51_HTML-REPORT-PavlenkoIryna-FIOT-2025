Завдання №1

Умова завдання

Зберегти введене значення часу (год:хвил) у змінну hour за допомогою методу prompt(). Вивести це значення у Console, використовуючи шаблонний рядок. Перевірити, до якої чверті години відноситься введене значення. Результат вивести за допомогою alert().

Програмний код


function task1() {
    
  const hour = prompt("Введіть час у форматі год:хвил");

  console.log(`Введений час: ${hour}`);

  if (hour === null || hour.trim() === "") {
    alert("Час не введено");
    return;
  }

  const parts = hour.split(":");
  const minutes = Number(parts[1]);

  if (minutes >= 0 && minutes <= 14) {
    alert("Перша чверть години");
  } else if (minutes >= 15 && minutes <= 29) {
    alert("Друга чверть години");
  } else if (minutes >= 30 && minutes <= 44) {
    alert("Третя чверть години");
  } else if (minutes >= 45 && minutes <= 59) {
    alert("Четверта чверть години");
  } else {
    alert("Некоректне значення часу");
  }
}

Результат виконання

При введенні значення 10:30 програма визначає відповідну чверть години та виводить результат за допомогою alert(). У Console відображається повідомлення: Введений час: 10:30.

Висновок

У процесі виконання завдання було використано функцію prompt() для введення даних користувачем, шаблонний рядок для виведення інформації в консоль та умовний оператор if...else для визначення чверті години за значенням хвилин.
