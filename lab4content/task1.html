Завдання №1

Умова завдання

Зберегти введене значення за допомогою методу prompt() у змінну value. Вивести це значення у Console, використовуючи шаблонний рядок. Перевірити: введене значення від’ємне, додатнє чи дорівнює нулю. Відповідь вивести за допомогою alert().

Програмний код


function task1() {
  const valueInput = prompt("Введіть число:");

  console.log(`Введене значення: ${valueInput}`);

  const value = Number(valueInput);

  if (valueInput === null || valueInput.trim() === "" || Number.isNaN(value)) {
    alert("Помилка: введіть коректне число");
  } else {
    if (value > 0) {
      alert("Число додатнє");
    } else if (value < 0) {
      alert("Число від'ємне");
    } else {
      alert("Число дорівнює нулю");
    }
  }
}

Результат виконання

При введенні значення 80 програма виводить повідомлення Число додатнє, а у Console відображається введене значення.

Висновок

У завданні було використано метод prompt() для введення даних, console.log() для виведення значення в консоль, перетворення рядка в число за допомогою Number() та умовний оператор if...else для перевірки числа.
