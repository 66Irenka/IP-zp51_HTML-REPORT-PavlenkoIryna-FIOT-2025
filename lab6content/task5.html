Завдання №5

Створити HTML-розмітку, яка складається з тексту з використанням селектора класу class="taskTitle" та блоку div з використанням селектора ідентифікатора id="place".

Додати слухач кліку на window і визначити, чи клікнув користувач у div з id="place". Якщо користувач клікнув на зеленому прямокутнику, у консолі виводиться true. В іншому випадку — false.

ЗАВДАННЯ 5

Програмний код


function task5() {
  const place = document.getElementById("place");

  if (!place) return;

  window.onclick = (event) => {
    console.log(place.contains(event.target));
  };
}

Результат виконання

Після натискання на зелений прямокутник у консолі відображається значення true. Якщо натиснути в будь-якому іншому місці сторінки, у консолі відображається false.

Висновок

У ході виконання завдання було використано обробник події click, об'єкт події event та метод contains(), який дозволяє перевірити, чи належить елемент, по якому виконано клік, до заданого блоку.
