Завдання №3

Створити HTML-розмітку, яка складається з тексту, кнопки та поля введення. Кнопка «Приховати» ховає введений текст, виводячи зірочки замість введеної інформації, та змінює назву кнопки на «Розкрити». При повторному натисканні текст знову стає доступним, а кнопка набуває початкового вигляду.

ЗАВДАННЯ 3

Програмний код


function task3() {
  const input = document.getElementById("passwordInput");
  const button = document.getElementById("togglePasswordBtn");

  if (!input || !button) return;

  button.addEventListener("click", () => {
    if (input.type === "text") {
      input.type = "password";
      button.textContent = "Розкрити";
    } else {
      input.type = "text";
      button.textContent = "Приховати";
    }
  });
}

Результат виконання

Після натискання кнопки текст у полі введення приховується, а кнопка змінює назву на «Розкрити». Після повторного натискання текст знову стає видимим.

Висновок

У завданні було використано обробник події click, зміну властивості type поля введення та зміну текстового вмісту кнопки за допомогою textContent.
