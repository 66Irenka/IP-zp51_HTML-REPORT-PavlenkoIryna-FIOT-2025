Завдання №9

Написати скрипт, який змінює колір фону сторінки при натисканні кнопки та відображає поточний колір у форматі HEX.

Background color: -

Програмний код


function getRandomHexColor() {
  return `#${Math.floor(Math.random() * 16777215)
    .toString(16)
    .padStart(6, "0")}`;
}

function task9() {
  const button = document.querySelector(".change-color");
  const colorText = document.querySelector(".color");

  if (!button || !colorText) return;

  button.onclick = () => {
    const color = getRandomHexColor();

    document.body.style.backgroundColor = color;
    colorText.textContent = color;
  };
}

Результат виконання

Після натискання кнопки Change color фон сторінки змінюється на випадковий колір, а його HEX-код відображається поруч із написом Background color.

Висновок

У ході виконання завдання було використано обробник події click, функцію генерації випадкового кольору getRandomHexColor(), властивість style.backgroundColor для зміни кольору фону сторінки та властивість textContent для відображення значення кольору на сторінці.
