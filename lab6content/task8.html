Завдання №8

Написати скрипт управління формою логіна. Обробка відправлення форми повинна відбуватися за подією submit. Сторінка не повинна перезавантажуватися. Якщо є незаповнені поля, потрібно вивести попередження All form fields must be filled in. Якщо всі поля заповнені, потрібно зібрати дані в об'єкт, вивести його в консоль і очистити форму методом reset().

Програмний код


function task8() {
  const form = document.querySelector(".login-form");

  if (!form) return;

  form.onsubmit = (event) => {
    event.preventDefault();

    const email = form.elements.email.value.trim();
    const password = form.elements.password.value.trim();

    if (email === "" || password === "") {
      alert("All form fields must be filled in");
      return;
    }

    const formData = {
      email,
      password,
    };

    console.log(formData);

    form.reset();
  };
}

Результат виконання

Якщо поля форми порожні, з'являється повідомлення All form fields must be filled in. Якщо користувач заповнив email і password, у консоль виводиться об'єкт із даними форми, після чого форма очищується.

Висновок

У ході виконання завдання було використано обробник події submit, метод preventDefault() запобігає перезавантаженню сторінки після надсилання форми., властивість elements для доступу до полів форми, метод trim() для очищення значень від зайвих пробілів та метод reset() для очищення форми після успішного відправлення.
