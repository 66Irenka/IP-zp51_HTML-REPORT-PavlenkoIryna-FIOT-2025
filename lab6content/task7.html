Завдання №7

Порахувати кількість категорій у списку ul#categories. Для кожного елемента li.item вивести в консоль назву категорії та кількість вкладених елементів.

  • Animals

    • Cat
    • Hamster
    • Horse
    • Parrot

  • Products

    • Bread
    • Parsley
    • Cheese

  • Technologies

    • HTML
    • CSS
    • JavaScript
    • React
    • Node.js

Програмний код


function task7() {
  const categories = document.querySelectorAll("#categories .item");

  console.log("Number of categories:", categories.length);

  categories.forEach(category => {
    const title = category.querySelector("h2").textContent;
    const elements = category.querySelectorAll("ul li").length;

    console.log("Category:", title);
    console.log("Elements:", elements);
  });
}

Висновок

У ході виконання завдання було опрацьовано навігацію по DOM-дереву, отримання елементів за допомогою селекторів та використання методу forEach(). Було реалізовано підрахунок кількості категорій і кількості елементів у кожній категорії з подальшим виведенням результатів у консоль.
