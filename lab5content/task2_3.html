Завдання №2.3

Умова завдання

Дано масив чисел [2, 4, 6, 8, 10]. Перевірити, чи є кожен елемент масиву парним. Очікуваний результат: true.

Програмний код


function task2_3() {
  const numbers = [2, 4, 6, 8, 10];

  const result = numbers.every(number => number % 2 === 0);

  console.log("Усі числа парні:", result);
}

Результат виконання

Метод every() перевіряє кожен елемент масиву. Оскільки всі числа парні, функція повертає значення true. 


Усі числа парні: true

Висновок

У ході виконання завдання було використано метод every(), який дозволяє перевірити, чи задовольняють усі елементи масиву задану умову.
