Завдання №1.9

Умова завдання

Для масиву об'єктів tweets підрахувати кількість використань кожного тегу та повернути об'єкт зі статистикою. Очікуваний результат: { js: 3, nodejs: 3, html: 2, css: 2, react: 2 }.

Програмний код


function task1_9() {
  const tweets = [
    { id: "000", likes: 5, tags: ["js", "nodejs"] },
    { id: "001", likes: 2, tags: ["html", "css"] },
    { id: "002", likes: 17, tags: ["html", "js", "nodejs"] },
    { id: "003", likes: 8, tags: ["css", "react"] },
    { id: "004", likes: 0, tags: ["js", "nodejs", "react"] },
  ];

  const tagStats = tweets
    .flatMap(tweet => tweet.tags)
    .reduce((acc, tag) => {
      acc[tag] = (acc[tag] || 0) + 1;
      return acc;
    }, {});

  console.log(tagStats);
}

Результат виконання

Після запуску функції у консоль виводиться об'єкт зі статистикою використання тегів: 


{
  js: 3,
  nodejs: 3,
  html: 2,
  css: 2,
  react: 2
}

Висновок

Під час виконання завдання було використано методи flatMap() та reduce(). За їх допомогою всі теги були об'єднані в один масив і підраховано кількість входжень кожного тегу.
