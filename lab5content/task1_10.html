Завдання №1.10

Умова завдання

Написати функцію checkBrackets(str), яка приймає рядок JavaScript-коду та перевіряє правильність закриття дужок (), {}, []. Якщо дужки розставлені правильно — повернути true, інакше — false.

Програмний код


function checkBrackets(str) {
  const stack = [];

  const pairs = {
    ")": "(",
    "}": "{",
    "]": "[",
  };

  for (const char of str) {
    if (char === "(" || char === "{" || char === "[") {
      stack.push(char);
    }

    if (char === ")" || char === "}" || char === "]") {
      if (stack.pop() !== pairs[char]) {
        return false;
      }
    }
  }

  return stack.length === 0;
}

Результат виконання

Для коректного рядка коду функція повертає true, а для рядка з помилками в дужках — false. 


Приклад 1: true
Приклад 2: false

Висновок

У ході виконання завдання було реалізовано алгоритм перевірки балансу дужок за допомогою структури даних стек. Функція коректно визначає правильність розташування та закриття дужок різних типів.
