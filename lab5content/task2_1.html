Завдання №2.1

Умова завдання

Дано масив об'єктів. Створити новий масив, який містить усі значення з масивів values кожного об'єкта.

Програмний код


function task2_1() {
  const data = [
    { id: 1, values: [1, 2, 3] },
    { id: 2, values: [4, 5, 6] },
    { id: 3, values: [7, 8, 9] },
  ];

  const result = data.flatMap(item => item.values);

  console.log(result);
}

Результат виконання

Після виконання функції всі вкладені масиви об'єднуються в один масив. 


[1, 2, 3, 4, 5, 6, 7, 8, 9]

Висновок

У ході виконання завдання було використано метод flatMap(), який дозволяє отримати значення з вкладених масивів та об'єднати їх в один новий масив.
