Завдання 1.5

Умова завдання

Напишіть функцію, яка приймає масив об'єктів і повертає новий масив. Необхідно зробити знижку 20% на всі фрукти у масиві та надати ідентифікатор (id) кожному продукту. Результат вивести у консоль.

Програмний код


function task1_5() {
  const fruits = [
    { name: "apple", price: 200 },
    { name: "orange", price: 300 },
    { name: "grapes", price: 750 },
  ];

  const discountedFruits = fruits.map((fruit, index) => ({
    id: index + 1,
    name: fruit.name,
    price: fruit.price * 0.8,
  }));

  console.log("Товари зі знижкою 20%:");
  console.log(discountedFruits);
}

Результат виконання

Після запуску функції створюється новий масив об'єктів. Кожному фрукту додається унікальний ідентифікатор, а ціна зменшується на 20%. Результат виводиться у консоль браузера.

Висновок

У ході виконання завдання було використано метод map() для створення нового масиву об'єктів. Також застосовано стрілочну функцію та виконано перетворення даних без зміни початкового масиву.
