Завдання 1.1

Написати функцію createProduct(obj, callback), яка приймає об'єкт товару без ідентифікатора та callback-функцію. Функція повинна створити новий об'єкт товару, додати йому унікальний ідентифікатор id та передати створений об'єкт у callback-функцію.

Створити callback-функції:

  • logProduct(product) — виводить об'єкт товару в консоль.
  • logTotalPrice(product) — виводить загальну вартість товару.

Програмний код


    function task1_1() {

  function createProduct(obj, callback) {
    const product = {
      id: Date.now(),
      ...obj,
    };

    callback(product);
  }

  function logProduct(product) {
    console.log("Інформація про товар:");
    console.log(product);
  }

  function logTotalPrice(product) {
    console.log(
      `Загальна вартість: ${product.price * product.quantity}`
    );
  }

  const product = {
    name: "Laptop",
    price: 25000,
    quantity: 2,
  };

  createProduct(product, logProduct);
  createProduct(product, logTotalPrice);
}

Результат виконання

Створено об'єкт товару з унікальним ідентифікатором. У консоль виводиться інформація про товар та загальна вартість замовлення. 


Інформація про товар:
{
  id: 1740000000000,
  name: "Laptop",
  price: 25000,
  quantity: 2
}

Загальна вартість: 50000
