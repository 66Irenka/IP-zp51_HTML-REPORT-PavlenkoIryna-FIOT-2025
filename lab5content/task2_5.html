Завдання №2.5

Умова завдання

Відсортувати масив рядків ["banana", "orange", "apple", "pear"] в алфавітному порядку. Очікуваний результат: ["apple", "banana", "orange", "pear"].

Програмний код


function task2_5() {
  const stringArray = ["banana", "orange", "apple", "pear"];

  const sortedArray = [...stringArray].sort();

  console.log("Відсортований масив:");
  console.log(sortedArray);
}

Результат виконання

Метод sort() сортує рядки в алфавітному порядку. Для збереження початкового масиву використано його копію за допомогою оператора розгортання .... 

Відсортований масив:
["apple", "banana", "orange", "pear"]

Висновок

У ході виконання завдання було використано метод sort() для сортування рядків в алфавітному порядку. Отримано новий відсортований масив без зміни вихідного масиву.
