Завдання №1.7

Умова завдання

Створити клас Client, який має властивості login та email. Оголосити приватні поля #login і #email. Доступ до них реалізувати через гетери та сетери.

Програмний код


class Client {
  #login;
  #email;

  constructor(login, email) {
    this.#login = login;
    this.#email = email;
  }

  get login() {
    return this.#login;
  }

  set login(newLogin) {
    this.#login = newLogin;
  }

  get email() {
    return this.#email;
  }

  set email(newEmail) {
    this.#email = newEmail;
  }
}

Результат виконання

Створюється об'єкт класу Client. Дані виводяться у консоль за допомогою гетерів. Після зміни значень через сетери оновлені дані також відображаються у консолі.

Висновок

Під час виконання завдання було створено клас із приватними полями. Для доступу до приватних властивостей використано механізм гетерів та сетерів, що забезпечує інкапсуляцію даних об'єкта.
